# Akyrion — Portfolio

The hub at https://akyrion.tech: Wang Guxiang's 1546 plum painting grows on screen, and every project hangs from its branches with its ink emblem, demo and code.
Static Astro site with a hand-made brush engine (Canvas 2D), in Spanish and English.

## Run locally

1. Install Node 24 and pnpm.
2. `pnpm install && pnpm build`
3. `pnpm preview` serves it at http://127.0.0.1:4400, with the demos from `../demos` mounted under their paths.
4. `pnpm verify` checks every page and demo in Chrome.
